一款小天才好友圈增强Xposed模块，具有强大功能（存疑？<br>
前身为`好友圈Ultimate-Xposed扩展`（为[好友圈Ultimate](https://github.com/sldjadkd/MomentUltimate)制作的模块）
## 主要功能
- 云控检测
- HTTPS请求/响应明文查看
- 主页增强
- ~~长按动态Dialog增强~~
- 发送自定义心情/动态 *（受限严重）*
- 集成DeepSeek API，用于AI美文
- 动态Dex加载 *（具体用法详见[这里](./AboutDexLoader.md)）*
- 加密通信 *（用于躲避审核）*
- 可顺便检查好友圈更新
- ...
> [!NOTE]
> 部分功能因特殊原因不可用
## 设备要求
- Android 7.1及以上
- Xposed API 82及以上
> [!IMPORTANT]
> 不支持[LSPatch](https://github.com/LSPosed/LSPatch)和虚拟Xposed环境，能用也会有功能缺失
> 目前仅在[EdXposed](https://github.com/ElderDrivers/EdXposed)环境下测试过，[Xposed](https://github.com/rovo89/XposedBridge)和[LSPosed](https://github.com/LSPosed/LSPosed)未进行测试，**理论适配**

> [!CAUTION]
> **尊贵的5100用户（[Z10](https://www.okii.com/html/mobile/products/z10.html)及以上）可能有兼容性问题。**
