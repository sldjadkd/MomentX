# MomentX
一款小天才好友圈增强Xposed模块，具有强大功能（存疑？<br>
前身为`好友圈Ultimate-Xposed扩展`（为[好友圈Ultimate](https://github.com/sldjadkd/MomentUltimate)制作的模块）
## 主要功能
- 云控检测
- HTTPS请求/响应明文查看
- 主页增强
- ~~长按动态Dialog增强~~ *（因云控暂时无法测试可用性，不公开）*
- 发送自定义心情/动态 *（虽然受限严重）*
- 集成DeepSeek API，用于AI美文
- 动态Dex加载
- 加密通信 *（用于躲避审核）*
- 可顺便检查好友圈更新
- ...
## 设备要求
- Android 7.1及以上
- Xposed API 82及以上


**注意：尊贵的5100用户可能有兼容性问题。**
